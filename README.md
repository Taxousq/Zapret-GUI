# Zapret GUI

Графическая оболочка для службы **zapret** — обхода блокировок от
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Вместо командной строки и `.bat`-файлов: переключение стратегий, запуск и остановка
службы, проверка доступности сайтов, обновления и логи — в одном окне.

**[Скачать последнюю версию](https://github.com/Taxousq/Zapret-GUI/releases)** ·
Windows 10/11 x64 · нужны права администратора

---

## ⚠️ Нужен официальный запрет от Flowseal

Приложение работает только с официальным
[Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube).
Сам обход блокировок оно не реализует — только управляет уже установленным запретом.

**Форки не поддерживаются** (HolyZapret, Zapret-Manager и другие): у них другая структура
папок, другие имена `.bat`-стратегий и свой `service.bat`, поэтому приложение не найдёт
ни папку запрета, ни стратегии, ни службу.

## Установка

1. Откройте [страницу релизов](https://github.com/Taxousq/Zapret-GUI/releases) и скачайте
   **`ZapretGUI-Setup-X.Y.Z.exe`**.
2. Запустите установщик: приложение встанет в `C:\Program Files\Zapret GUI`, появятся
   ярлыки в «Пуск» и на рабочем столе.
3. Запустите **Zapret GUI**. Если запрет ещё не скачан, откроется мастер первого запуска.

**Портативная версия** — `ZapretGUI-Portable-X.Y.Z.exe`: работает без установки и без прав
администратора, настройки хранит рядом с exe. Автообновления у неё нет — новую версию
нужно скачать вручную.

**Требования:** Windows 10/11 x64, права администратора (установщик, служба), интернет для
скачивания запрета и проверки обновлений.

## Первый запуск

Приложение само ищет папку запрета: сначала по пути службы `zapret` в реестре, затем
подпапки с именем на `zapret` на дисках и в типичных местах (Загрузки, Рабочий стол,
`%LOCALAPPDATA%`). Папка считается запретом, если в ней есть `service.bat` или `bin\winws.exe`.

Если папка не нашлась, мастер первого запуска предлагает три пути:

- **Скачать с GitHub** — последний релиз Flowseal скачивается в выбранную папку. Службу
  после этого нужно поставить вручную: запустите в папке запрета `service.bat` от имени
  администратора и выберите `Install Service`.
- **Указать папку вручную** — если запрет уже распакован.
- **Искать везде** — обход локальных дисков; долго, поэтому только по кнопке.

Сменить папку позже можно в **«Настройках»**: «Изменить папку», «Проверить папку»,
«Скачать заново с GitHub».

## Разделы

| Раздел | Что делает |
|---|---|
| **Обзор** | Плитка службы с кнопками «Запустить» / «Остановить» / «Перезапустить», текущая стратегия, быстрые действия, график пинга |
| **Служба** | Старт, стоп, перезапуск службы `zapret`, автозапуск программы |
| **Стратегии** | Список `.bat`-стратегий запрета, установка и переустановка службы с выбранной, удаление службы |
| **Списки** | Правка `list-general-user.txt` и `list-exclude.txt` с бэкапом и откатом |
| **Обход (WARP)** | Управление установленным Cloudflare WARP: состояние, подключение, режим, исключения Split Tunnel |
| **TG WS Proxy** | Локальный MTProto-прокси для Telegram: статус, запуск, путь к exe |
| **Тестирование** | «Проверить текущую» и «Тестировать все» — перебор стратегий с таблицей по сайтам и применением лучшей |
| **Проверка связи** | Быстрая проверка YouTube, Discord, Instagram, Telegram, Google |
| **Обновление** | Четыре источника: запрет, интерфейс, WARP, TG WS Proxy |
| **Логи** | Журнал Windows по службе `zapret` |
| **Настройки** | Папка запрета и место хранения настроек |

Мелочи, которые заметны каждый день: закрытие окна сворачивает приложение в трей (полный
выход — через меню иконки), тема переключается в шапке и запоминается, без прав
администратора в шапке висит предупреждение, долгие операции идут в фоне и не подвешивают окно.

## Стратегии и служба — коротко

Запрет работает как **служба Windows** `zapret`, которая запускает `winws.exe` с аргументами
выбранной стратегии. **Стратегия** — это `.bat`-файл из папки запрета (`general (ALT11).bat`
и подобные): разные стратегии по-разному обходят DPI, и какая сработает — зависит от
провайдера. Поэтому в приложении есть тестер: он перебирает стратегии и показывает, где
работают YouTube, Discord и остальные сайты.

## Автообновление

Раздел **«Обновление»** — четыре карточки, у каждой своя версия и кнопка «Проверить
обновление»; сверху общая кнопка «Проверить всё».

- **Интерфейс** — сам GUI: проверка при запуске и раз в сутки, баннер в шапке, скачивание
  установщика и его запуск.
- **Запрет** — из релизов Flowseal, с заменой файлов папки запрета.
- **Cloudflare WARP** — версия проверяется через `winget`, обновляет сам Cloudflare.
- **TG WS Proxy** — замена exe из релизов Flowseal.

## Частые проблемы

**«Запрет не найден».** Нажмите в мастере «Искать везде» или укажите папку вручную
(«Настройки» → «Изменить папку»). Признак верного пути — `bin\winws.exe` или `service.bat`.

**«Служба не установлена», хотя запрет скачан.** Приложение не ставит службу само:
запустите в папке запрета `service.bat` от имени администратора → `Install Service`.

**«Отказано в доступе».** Приложение запущено без прав администратора — перезапустите его
от имени администратора.

**Служба стартует и сразу останавливается.** Окно ошибки показывает вывод `winws.exe`.
Обычные причины: порт занят другим VPN или прокси, запущен второй экземпляр запрета, не
хватает файлов (`bin\winws.exe`, `lists`), службу надо перезапустить после обновления.
Полный журнал — в разделе «Логи».

**Проверка сайтов показывает таймауты.** Попробуйте другую стратегию (например `ALT11` или
`ALT12`) — результат зависит от вашей сети.

**Не ставится новая стратегия, обновление не копирует файлы.** Служба запущена и держит
`winws.exe`. Приложение останавливает её само; если не смогло — остановите вручную
и повторите.

**Не нашёлся Cloudflare WARP или TG WS Proxy.** Эти программы приложение не устанавливает:
поставьте их отдельно (WARP — с cloudflare.com/warp), для TG WS Proxy можно указать путь
к exe вручную.

**Где журнал приложения.** `%LOCALAPPDATA%\ZapretGUI\zapret-gui.log`, в портативной версии —
`logs\zapret-gui.log` рядом с exe.

## Ограничения

- Обход блокировок не реализуется — только управление установленным запретом.
- Папка запрета не входит в поставку: скачивается при первом запуске или указывается вручную.
- Файлы запрета не изменяются: приложение их читает и запускает. Исключение — обновления
  и скачивание, которые заменяют файлы по вашему подтверждению.
- Cloudflare WARP раздел не устанавливает и не обновляет — только управляет через `warp-cli`.
- Автообновление есть только у установленной версии; портативную обновляют вручную.
